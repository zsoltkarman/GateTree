# GateTree 0.4.3

## Safer Notes editing

- Added native Undo and Redo support with ⌘Z and ⇧⌘Z in the note editor.
- Notes now show an **Unsaved changes** indicator. Closing a changed note or
  switching to another note/folder asks whether to save, discard, or continue.
- Save keeps the note open; Close is now the explicit way to leave its editor.
- Selecting the Connections tree closes the Notes workspace instead of leaving
  it over the connection area.

## Compact window support

- Quick Access favorites retain a visible horizontal scrollbar when the window
  is narrow, so no favorites become inaccessible.
